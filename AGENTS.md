# Agent instructions

This repository contains reusable Agent Ops skills and the distributed coordinator. Use the linked Linear issue for acceptance criteria and scope. Target `main` from an isolated issue worktree and include the issue key in the branch and PR title.

- Run the [required checks](docs/agents/verification.md) before requesting review.
- Follow the [review policy](docs/agents/review-standards.md) for independent quality and spec review.
- A distributed run requires an approved Hermes route. Keep host configuration and credentials outside this repository. The owner merges the verified PR.
